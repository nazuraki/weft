What it does

account_tree

Graph-native navigation

Documents are nodes. Cross-references are typed edges. Navigate by following links at anchor resolution, not just file level.

hub

Heterogeneous artifacts

Markdown, OpenAPI specs, YAML, and diagrams all coexist as first-class nodes. One tool for your entire documentation surface.

search

Full-text search

Instant fuzzy search across all nodes and anchors. Find the right context in milliseconds without leaving the browser.

integration_instructions

Embeddable

Drop the Weft browser into any page with a single script tag. Point it at a GitHub repo or any base URL — no server required.

Embed anywhere

The Weft browser is a self-contained IIFE bundle. Load it from your CDN, point it at a repo, and your documentation is live.

import { mountWeft } from '@lepid-labs/weft-embed'; mountWeft('#docs', { repo: 'acme/my-project', });
